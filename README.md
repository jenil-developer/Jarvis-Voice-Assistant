# 🤖 Jarvis AI Voice Assistant

A smart and responsive desktop voice assistant built using **Python, Tkinter, and pyttsx3**. This project was specifically optimized to solve threading and DLL path handling issues in advanced Python environments (Python 3.14+).

## 🚀 Features
- **Smart Time-Based Greeting:** Automatically greets as Good Morning/Afternoon/Evening.
- **Dynamic Date & Day Announcement:** Speaks the current day and date seamlessly using Python's native audio queue logic.
- **Web Automation:** Quick voice-triggered buttons to launch Google and YouTube instantly.
- **Custom Modern UI:** Clean, dark-themed interface built using Tkinter.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **GUI Framework:** Tkinter
- **Text-to-Speech Engine:** pyttsx3 (SAPI5 Windows Driver)
- **Automation:** Webbrowser, Datetime, OS, Sys
